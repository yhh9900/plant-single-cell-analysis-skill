# 编号式注释 UMAP 样式

按照用户示例制作左右两部分组成的 UMAP。

## 左侧 UMAP

- 白色背景，只保留黑色左轴和下轴，不使用灰色背景和网格线。
- 每个 cluster 使用稳定且互相区分的颜色，细胞点较小。
- 在 cluster 的中位数中心附近显示黑色加粗编号 `1..N`。
- 不把长细胞类型名称直接写在点云上。
- 坐标轴命名为 `UMAP_1` 和 `UMAP_2`，保留清晰的刻度。

## 右侧注释区

- 按展示编号顺序一行一个 cluster。
- 每行先画带细黑边的彩色圆点，在圆点内部写编号。
- 圆点右侧写最终注释名称。
- 不再显示 ggplot 自动生成的第二套图例。

## 整张图

- 上方居中显示加粗的样本或项目标题。
- 左侧 UMAP 近似正方形，右侧预留足够宽度，避免长注释被裁切。
- 使用相同尺寸和颜色同时输出 300 dpi PNG 与矢量 PDF。
- 另存编号映射表，包含原始 cluster ID、展示编号、颜色、基础注释、前缀 marker 和最终注释。

读取 `scripts/plot_numbered_umap.R` 后调用 `plot_numbered_umap()`。输入数据框每行代表一个细胞，必须包含 UMAP 坐标、cluster ID 和最终注释。
